# 기능 목록
## 기본 입출력 구현
- feat: 기본 입출력 기능 구현
- 안내 문구를 출력하고, 사용자 입력을 받으며, 기본 결과를 출력하는 프로그램의 골격을 구현한다.

## 빈 문자열 및 null 값 처리
- feat: 빈 문자열 또는 null 입력 처리 기능 구현
- 입력값이 비어있거나 null일 경우 0을 반환한다.

## 기본 구분자(쉼표, 콜론) 처리
- feat: 기본 구분자(쉼표, 콜론) 처리 기능 구현
- 쉼표(,) 또는 콜론(:)을 기준으로 문자열을 분리하여 합을 계산한다.

## 커스텀 구분자 처리
- feat: 커스텀 구분자 처리 기능 구현
- //와 \n 사이의 문자를 커스텀 구분자로 사용하여 합을 계산한다.

## 예외 처리 - 음수 입력
- feat: 음수 입력 시 예외 처리 기능 추가
- 입력값에 음수가 포함되어 있을 경우 IllegalArgumentException을 발생시킨다.

## 예외 처리 - 숫자 이외의 값
- feat: 숫자 이외의 값 입력 시 예외 처리 기능 추가
- 입력값에 숫자로 변환할 수 없는 문자가 포함된 경우 IllegalArgumentException을 발생시킨다.
